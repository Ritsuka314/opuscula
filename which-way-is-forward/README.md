# Which Way Is Forward?

A bilingual essay on the directions we give time, beginning with Mandarin
前／後 and moving through schedules, time zones, clock errors, progress, stories,
and browser history.

The English and Traditional Chinese sources are `article-en.md` and
`article-zh.md`. Their matching section markers produce one publication page
with the collection's existing language controls. The meeting-date question
uses a native HTML disclosure, so readers can try it before revealing the two
interpretations, including without JavaScript.

Research and dictionary links appear beside the claims they support. The
reading, film, and browser examples are illustrative scenarios developed for
the essay, rather than reported experiments.

From the Opuscula root:

```sh
npm run build
npm run check
```

Edit the Markdown sources and the record in `src/data/writings.json`, then
regenerate `index.html`; the HTML is committed output.
