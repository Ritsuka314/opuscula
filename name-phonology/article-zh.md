## 同一個名字，兩種讀法

把<ruby lang="ja">御坂美琴<rp>（</rp><rt>みさか みこと</rt><rp>）</rp></ruby>
先讀成 *Misaka Mikoto*，再讀成 *<span lang="zh-Latn-pinyin">Yùbǎn Měiqín</span>*。字沒有變，名字的節奏卻換了。
日語中，姓與名各佔三拍；普通話中，它有四個音節、兩個鼻音韻尾，以及一組在連讀時
會發生變化的聲調。紙上看似相同的名字，到了口中，便成了兩件頗不相同的事。

人名雖短，卻是聽見一種語言聲音結構的熟悉入口。動畫、漫畫、遊戲及相關作品中的
名字，正好提供了便於比較的例子。許多讀者早已熟悉
兩種讀法，卻未必問過：為何 *Hakurei Reimu* 和「博麗靈夢」聽起來如此不同？
從已經聽過、記得的名字出發，我們可以逐一辨認：這份印象中，有哪些結構能說清楚？

本文的漢語比較限於**現代標準普通話**；日語以當代標準語為主，談到音高重音時，
以東京式重音為參照。這是對現代讀音的共時比較，不是古音重建。例子用來幫助我們
聽見結構，並不據此推斷創作者當初的命名意圖。

主要例子是《科學超電磁砲》的御坂美琴、《東方 Project》的博麗霊夢與霧雨魔理沙，
以及虛擬歌手初音ミク、鏡音リン。各官方角色頁列出了相應的日語讀法。
（[御坂美琴][misaka]、[博麗霊夢][reimu]、[霧雨魔理沙][marisa]、
[Piapro 角色介紹][piapro]）

| 日文寫法 | 日語讀法 | 本文採用的中文形式及普通話讀音 |
| --- | --- | --- |
| <span lang="ja">御坂美琴</span> | <ruby class="name-reading" lang="ja">みさか<rp> (</rp><rt lang="ja-Latn">Misaka</rt><rp>)</rp></ruby> <ruby class="name-reading" lang="ja">みこと<rp> (</rp><rt lang="ja-Latn">Mikoto</rt><rp>)</rp></ruby> | 御坂美琴 · <span lang="zh-Latn-pinyin">Yùbǎn Měiqín</span> |

| <span lang="ja">霧雨魔理沙</span> | <ruby class="name-reading" lang="ja">きりさめ<rp> (</rp><rt lang="ja-Latn">Kirisame</rt><rp>)</rp></ruby> <ruby class="name-reading" lang="ja">まりさ<rp> (</rp><rt lang="ja-Latn">Marisa</rt><rp>)</rp></ruby> | 霧雨魔理沙 · <span lang="zh-Latn-pinyin">Wùyǔ Mólǐshā</span> |

這裡有兩種不同的對應。「御坂美琴」是在兩種語言中讀相同的漢字；日文「霊」在
本文中文形式中寫作「靈」。「初音ミク」還涉及寫法的改變：ミク是片假名，「未來」
則是 [Crypton 繁體中文角色頁][piapro-zh]採用的中文名稱；「鏡音鈴」也取自該頁。
不能先悄悄把日文名字改寫成全漢字，再把這個寫法當成原名。表中的拼音與下文的
結構分析由本文補出。

漢字數量也不能決定日語的節奏。「琴」在普通話中是一個音節 *<span lang="zh-Latn-pinyin">qín</span>*，在 *Mikoto*
中卻對應兩拍「こと」；*Kirisame* 的「雨」對應「さめ」，不能把單獨選出的
「あめ」直接接在「きり」後面。必須先確定整個名字的讀法，才能計算它的聲音單位。

## 「開」有三種意思

名字可以聽起來開闊、圓潤、緊窄，或富於共鳴。把三種不同的語音性質分開之後，
這些印象才能成為比較準確的描述。

### 四呼：韻母如何開始

普通話的傳統分析以聲母、韻母、聲調描述音節。韻母可以包含韻頭、韻腹與韻尾；
四呼主要看韻頭，沒有韻頭時則看韻腹。
（[維基百科：四呼][sihu]）

| 類別 | 基本判準 | 例字 |
| --- | --- | --- |
| 開口呼 | 無韻頭，韻腹又不是 <span lang="zh-Latn-pinyin">i、u、ü</span> | 沙 <span lang="zh-Latn-pinyin">shā</span> |
| 齊齒呼 | 韻頭或韻腹為 <span lang="zh-Latn-pinyin">i</span> | 琴 <span lang="zh-Latn-pinyin">qín</span> |
| 合口呼 | 韻頭或韻腹為 <span lang="zh-Latn-pinyin">u</span> | 未 <span lang="zh-Latn-pinyin">wèi</span>，韻母 <span lang="zh-Latn-pinyin">uei</span> |
| 撮口呼 | 韻頭或韻腹為 <span lang="zh-Latn-pinyin">ü</span> | 雨 <span lang="zh-Latn-pinyin">yǔ</span>，元音 <span lang="zh-Latn-pinyin">ü</span> |

拼音字母需要解讀。*<span lang="zh-Latn-pinyin">yǔ</span>* 中的 <span lang="zh-Latn-pinyin">u</span> 表示 <span lang="zh-Latn-pinyin">ü</span>；*<span lang="zh-Latn-pinyin">wèi</span>* 所屬的韻母是 <span lang="zh-Latn-pinyin">uei</span>。反過來，
*<span lang="zh-Latn-pinyin">shi</span>*、*<span lang="zh-Latn-pinyin">zhi</span>* 中的 <span lang="zh-Latn-pinyin">i</span>，並不是 *<span lang="zh-Latn-pinyin">mī</span>* 中那個普通的 <span lang="zh-Latn-pinyin">i</span> 元音。<span lang="zh-Latn-pinyin">zhi、chi、shi、ri</span>
的韻母，傳統上歸入開口呼。因此，「開口呼」並不等於「把嘴張得很大」，更不
等於「名字聽起來開闊」。（[維基百科：普通話韻母及其分類][finals]）

### 鼻音韻尾：音節如何結束

開音節以元音結束，閉音節則有輔音韻尾。對本文的普通話名字，一個實用的區分是：
韻母是否以鼻輔音 <span lang="zh-Latn-pinyin">-n</span> 或 <span lang="zh-Latn-pinyin">-ng</span> 收尾。不帶這兩種韻尾的韻母，既包括單元音，也包括
帶元音性尾部滑動的複合元音。（[普通話韻母的結構][finals]）

以下用 **N** 表示鼻音收尾，**V** 表示本文例子中不帶鼻音韻尾的情形。V 不代表
「只有一個元音音素」：*<span lang="zh-Latn-pinyin">měi</span>*、*<span lang="zh-Latn-pinyin">lái</span>* 也歸在這一組。這只是記錄韻尾特徵的簡寫，
不藉此裁定滑音在所有音系理論中的地位。分隔符標出名字兩部分的邊界，不表示
必須停頓。

| 普通話形式 | 收尾模式 | 帶鼻音韻尾的音節 |
| --- | --- | --- |
| 御坂美琴 | VN · VN | <span lang="zh-Latn-pinyin">bǎn</span>、<span lang="zh-Latn-pinyin">qín</span> |
| 博麗靈夢 | VV · NN | <span lang="zh-Latn-pinyin">líng</span>、<span lang="zh-Latn-pinyin">mèng</span> |
| 霧雨魔理沙 | VV · VVV | 無 |
| 初音未來 | VN · VV | <span lang="zh-Latn-pinyin">yīn</span> |
| 鏡音鈴 | NN · N | <span lang="zh-Latn-pinyin">jìng</span>、<span lang="zh-Latn-pinyin">yīn</span>、<span lang="zh-Latn-pinyin">líng</span> |

「御坂美琴」重複了「非鼻音收尾—鼻音收尾」的模式；「博麗靈夢」把兩個鼻音
韻尾集中在名的部分。「鏡音鈴」每個音節都以鼻音結束，「霧雨魔理沙」則完全
沒有鼻音韻尾。「流動」「收束」之類的聽感，可能就在回應這些具體差異。

鼻音韻尾並不天生沉重。有的聽者反而會覺得它的共鳴柔和、連貫。可以直接記錄的是
韻尾出現的位置；它產生什麼審美效果，仍需回到聆聽。

### 元音開口度：音節內部發生什麼

元音高低是另一個維度。低元音 <span lang="zh-Latn-pinyin">a</span> 的發音構形比高元音 <span lang="zh-Latn-pinyin">i、u、ü</span> 更開；嘴唇是否
圓攏又是另一回事。像 <span lang="zh-Latn-pinyin">uan</span> 這樣的韻母，先從圓唇的韻頭移向低元音，再以鼻音
收尾。（[維基百科：普通話元音的發音描述][vowels]）

「霧雨魔理沙」讓這個區分很容易聽見。五個音節都沒有鼻音韻尾，但開頭的 <span lang="zh-Latn-pinyin">wù</span>、<span lang="zh-Latn-pinyin">yǔ</span>
是高而圓唇的元音，結尾 <span lang="zh-Latn-pinyin">shā</span> 卻落在低元音上。它的韻尾類型整齊一致，內部的
元音運動卻不一致。只用一個「開」字概括整個名字，恰好會漏掉其中有趣的變化。

## 聲調數字不是旋律

普通話的四個完整詞彙聲調通常編為 1–4：高平、上升、低或曲折、下降。數字表示
類別，並非四個音樂音高。上聲在連續語流中常常不帶單念時的後半段上升；在同一
變調域內，兩個上聲相接，前一個通常變為升調。
（[普通話的上聲變調][mandarin]）

| 名字 | 詞彙聲調 |
| --- | --- |
| 御坂美琴 | 4–3 · 3–2 |
| 博麗靈夢 | 2–4 · 2–4 |
| 霧雨魔理沙 | 4–3 · 2–3–1 |
| 初音未來 | 1–1 · 4–2 |
| 鏡音鈴 | 4–1 · 2 |

「御坂美琴」尤其適合說明這一點。兩個上聲恰好在姓與名的交界相遇：<span lang="zh-Latn-pinyin">bǎn</span> | <span lang="zh-Latn-pinyin">měi</span>。
若整個名字連成同一個變調域，這一對中的前字便讀成升調，可以簡記為
**4–2–3–2**。若在姓後有足夠強的停頓或韻律邊界，組合方式就改變了。上表拼音
記的是詞彙聲調，並非每次實際發音的精密轉寫。

「博麗靈夢」提供另一種重複：**2–4 | 2–4**。姓與名都重現升—降的聲調類別，
但鼻音韻尾只出現在後半。就我的聽感而言，這使普通話的名字比日語讀法更有成對
往復的感覺。這是對結構的詮釋，並不是對美感的測量。

「初音未來」先有兩個高平調，再轉入降調與升調。詞彙層面有清楚的輪廓變化，
但要知道實際時長與音域，仍然需要一段具體發話。輕聲自我介紹、驚訝地呼喊、
在歌詞中唱出，都不會把同一個名字說成完全相同的樣子。聲調屬於名字的讀音；
語調則參與說話者當下如何使用這個名字。

## 日語用什麼計算長短？

日語的 **mora（音拍，亦稱「拍」）**是音系中的計量單位。短元音連同可能出現的
前接輔音，通常算一拍；長元音算兩拍。撥音「ん」和以小「っ」表示的促音部分，
各佔一拍。小「ゃ・ゅ・ょ」則與前面的假名結合：「きゃ」是一拍，「きや」是
兩拍。[國立國語研究所的音拍表][ninjal]明列了這些區別。

| 名字 | 音拍劃分 | 拍數 |
| --- | --- | --- |
| Misaka Mikoto | <span lang="ja">み・さ・か ｜ み・こ・と</span> | 3+3 |
| Hakurei Reimu | <span lang="ja">は・く・れ・い ｜ れ・い・む</span> | 4+3 |
| Kirisame Marisa | <span lang="ja">き・り・さ・め ｜ ま・り・さ</span> | 4+3 |
| Hatsune Miku | <span lang="ja">は・つ・ね ｜ ミ・ク</span> | 3+2 |
| Kagamine Rin | <span lang="ja">か・が・み・ね ｜ リ・ン</span> | 4+2 |

*Rin* 很適合用來反駁「數元音就是數拍」或「數音節就是數拍」的直覺。リン 通常
是一個音節，卻有兩拍：鼻音也計數。*Miku* 同樣有兩拍，但分布在兩個短音節中。
拍數相同，內部結構仍然不同。

同樣地，*Hakurei Reimu* 和 *Kirisame Marisa* 都是 4+3。前者寫作「れい」的
部分可以實現為長 e 元音，而兩拍的音系長度仍保留；後者則由七個短的輔音—元音
音節組成。重複的長元音序列與接連的短音節，可以佔據相同的拍數。

[窪薗晴夫對音拍與音節的論述][mora]說明了為什麼日語同時需要這兩種結構。
數拍是在描述音系長度，並不要求每拍精確佔用相同的毫秒數。沒有充分發聲的元音，
也未必代表少了一拍：[元音無聲化][ninjal]本來就是日語語音的一部分，不能據此
認為節奏單位已經消失。

## 聽見名字中的重複

*Misaka Mikoto* 的姓與名都以「み」開始。粗略記下元音，得到：

> **i–a–a | i–o–o**

兩組長度相同，都以 mi 開頭，末尾又各有一對相同元音。不必先指定某個音高重音，
也能聽見這種對稱。普通話 *<span lang="zh-Latn-pinyin">Yùbǎn Měiqín</span>* 並不保留這個模式，卻以
**VN | VN** 的韻尾組合建立了另一種對應。

*Kirisame Marisa* 的粗略元音序列是：

> **i–i–a–e | a–i–a**

姓與名之間還重複了 ri 和 sa。指出這些回聲，比籠統地說名字「有音樂性」更具體。
普通話用同一組漢字，產生的卻是另一套元音與聲調序列。文字延續下來，不代表
每個聲音、每種重複也都延續下來。

元音表仍然是一種簡化。它略去了輔音，只粗分元音，也幾乎不告訴我們音高與表達
方式。它的用途，是讓我們一次指出一個模式，再回到完整的名字，聽這些模式如何
一起起作用。

<!-- section: accent -->
## 羅馬字之外的聲音

東京式詞彙重音關心的是音高下降的有無與位置，包括有重音與無重音詞的區分。
它不是給每個漢字各配一個普通話式聲調，也不是英語式的輕重音。知道一個名字是
4+3 拍，還不知道它的重音如何配置。
（[音拍、音節與重音][mora]）

因此，上面的音拍劃分沒有附上臆定的重音符號。若要分析角色名字在作品中的實際
重音，需要辨明是哪個說話者、在什麼語境下說的。呼喊、歌唱與平常介紹，是不同
性質的材料。OJAD 可以幫助呈現韻律，但其文件明確把任意文本的輸出稱為**推定**。
自動產生的輪廓，不能單憑自身決定某個角色名在作品中的讀法。
（[OJAD 的四種功能][ojad]）

羅馬字也容易誘使我們把代表不同聲音的字母拿來直接比較。日語 *Marisa* 的 sa
是「さ」，普通話 *<span lang="zh-Latn-pinyin">Mólǐshā</span>* 的 <span lang="zh-Latn-pinyin">sh</span> 卻表示捲舌的噝音。*<span lang="zh-Latn-pinyin">qín</span>* 中的 <span lang="zh-Latn-pinyin">q</span> 是送氣的
舌面前塞擦音，也不是英語讀者可能依字母 q 猜出的聲音。
（[維基百科：普通話聲母的發音描述][consonants]）

保留漢字，未必保留名字的聲音質地。有效的比較要同時追蹤輔音、元音、時長與
音高，而文字則讓我們知道：這些不同的發音，指向同一個角色。

## 聲音與聯想

看到一位熟悉的女主角，注意到她名字裡的高元音或短結尾，很容易便推論：正是
這些聲音造就了女性感或可愛感。但這個名字早已帶著聲線、面孔、故事，以及反覆
接觸的記憶。我們對聲音的反應，已經混入了對角色的認識。

研究可以辨認命名慣例，卻不必把它化約為元音的普遍本性。Barešová、Nakaya 與
Matlach 對當代日本名字的研究，發現名字結尾等特徵與性別類別之間存在關聯；
只看最後一個元音，則不足以解釋這些差異。熟悉的聲音序列可以在使用中取得
聯想，卻不因此天生屬於女性，也不能決定每一位使用者的性別身分。
（[Gender-specific features in contemporary Japanese names，2024][names]）

本文幾個角色不構成日本名字的代表性樣本，音系也不能獨自解釋他們為何受歡迎。
但它們讓我們能提出更好的問題：*Misaka Mikoto* 重複的 mi，是否參與了名字的
聽感？「靈夢」的鼻音韻尾與「魔理沙」的元音收尾，對普通話聽者有什麼差別？
不認識角色的人，會不會作出相同的描述？前兩個問題關乎可聽見的結構，第三個
則開始把聲音與後天的喜愛分開。

一個簡單的聆聽練習，是比較同一個名字在兩種語言的日常介紹中如何出現。先標出
邊界、普通話的詞彙聲調與韻尾、日語的音拍，再聽記號所略去的部分：輔音、實際
音高、語速與表達方式。先描述差異，再作判斷。

「御坂美琴」不需要在兩種語言中保留同一種對稱，仍能是那個熟悉的名字。
*Misaka Mikoto* 重複開頭與三拍的形狀；*<span lang="zh-Latn-pinyin">Yùbǎn Měiqín</span>* 重複韻尾模式，同時
處理相鄰上聲的連讀。一個書寫形式，可以容納不止一種聲音上的整合方式。
學會聽見這些不同的方式，正是名字音系分析有趣的地方。
